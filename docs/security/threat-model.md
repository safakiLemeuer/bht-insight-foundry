# Threat Model

Initial threats to test:

1. Direct prompt injection
2. Indirect prompt injection embedded in documents
3. Unauthorized retrieval
4. Cross-user data leakage
5. Hallucinated or incorrect citations
6. Secret exposure
7. Malicious or oversized files
8. Excessive token or API consumption
9. Sensitive-data logging
10. Dependency compromise

Each threat must have a documented control, test case, and residual-risk statement before production use.
